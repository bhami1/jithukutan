# Abhijith V — Developer Portfolio

A developer portfolio website crafted for **Abhijith V**, built with **React 19**, **Vite**, **Tailwind CSS**, and **Framer Motion**.

Featuring an Awwwards-inspired luxury dark aesthetic, obsidian surfaces, electric violet/cyan accents, authentic photography, verified GitHub repository highlights, and an interactive system specs terminal.

---

## ⚡ Tech Stack

- **Framework**: React 19 + Vite 6
- **Styling**: Tailwind CSS 3 (Glassmorphism, custom typography, dark palette)
- **Animation**: Framer Motion 12 (spring physics, layout transitions, scroll triggers)
- **Icons**: Lucide React + Custom SVG Brand Badges
- **Typography**: Space Grotesk, Plus Jakarta Sans, JetBrains Mono

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run Local Development Server
```bash
npm run dev
```

### 3. Build for Production
```bash
npm run build
```

### 4. Preview Production Build
```bash
npm run preview
```
